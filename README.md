# 1С: Помощник

Приложение для клиентов компании «1С: Франчайзи». В нём можно отправить заявку специалисту, следить за её выполнением, прочитать полезные советы по 1С и найти контакты компании.

## Открыть приложение

👉 **https://ВАШ-ЛОГИН.github.io/1c-pomoshnik/**

Приложение работает в браузере на телефоне и на компьютере, устанавливать ничего не нужно.

Если первая загрузка идёт долго (до минуты), подождите: сервер просыпается после простоя. Дальше всё работает быстро.

**Как добавить на главный экран телефона:**
* Android (Chrome): меню ⋮ → «Добавить на главный экран»
* iPhone (Safari): кнопка «Поделиться» → «На экран „Домой“»

## Как пользоваться

**1. Зарегистрируйтесь.** Укажите имя, компанию, телефон или email и придумайте пароль.

**2. Создайте заявку.** Нажмите «Создать заявку» и заполните:
* программу 1С, с которой возник вопрос;
* тип проблемы: ошибка, консультация, доработка, обновление, настройка отчёта или другое;
* описание: что делали, что произошло, текст ошибки;
* срочность.

**3. Следите за статусом** в разделе «Мои заявки». Статусы такие:

| Статус | Что значит |
|---|---|
| Новая | Заявка отправлена и ждёт специалиста |
| Принята | Специалист ознакомился с заявкой |
| В работе | Специалист решает вопрос |
| Выполнена | Готово, результат описан в комментарии |

Когда специалист отвечает, на вкладке «Заявки» появляется красная цифра.

**4. Полезные материалы.** Короткие инструкции: как сделать копию базы, как обновить программу, что значат частые ошибки, горячие клавиши.

**5. Контакты.** Телефон, email и адрес компании, кнопка «Позвонить».

## Для специалистов компании

Админ-панель: **https://ВАШ-ЛОГИН.github.io/1c-pomoshnik/admin/**

Войдите под учётной записью специалиста; логин и пароль выдаёт администратор. В панели видны все заявки, их можно фильтровать, менять статус и отвечать клиенту.

## Запустить на своём компьютере

Нужны установленные Node.js и PostgreSQL.

1. Создайте базу данных: в pgAdmin откройте Query Tool и выполните по очереди две команды:
   ```sql
   CREATE USER pomoshnik WITH PASSWORD 'pomoshnik';
   ```
   ```sql
   CREATE DATABASE pomoshnik OWNER pomoshnik;
   ```
2. В папке проекта выполните:
   ```
   npm install
   copy .env.example .env
   npm run db:init
   npm start
   ```
3. Откройте:
   * http://localhost:3000 — приложение;
   * http://localhost:3000/admin — админ-панель (логин `admin@example.com`, пароль `Admin12345`).
